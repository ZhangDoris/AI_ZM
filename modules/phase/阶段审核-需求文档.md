# 2.3 阶段审核改造

阶段审核改造是临床研究智能预筛系统的核心审批模块，支持审批类型、审批阶段、项目阶段三层可配置模型，实现预筛、筛选、入组等各临床研究阶段的统一审批流程电子化管理。


---

## 2.3.1 审批类型配置

### 2.3.1.1 功能描述

审批类型配置是阶段审核改造的基础数据模块，用于统一管理审批类型名称、编码、排序、颜色、图标等属性。管理员可在系统管理中对审批类型进行新增、修改、删除、启用/停用操作，并支持在列表中通过上移/下移按钮直接调整排序，为后续审批阶段和项目阶段配置提供标准化数据源。

### 2.3.1.2 能力要求

- 能够对审批类型进行新增，填写审批类型名称、编码、排序、颜色、图标、备注等信息
- 能够对审批类型进行修改，加载选中记录后编辑保存
- 能够对审批类型进行删除，删除前校验是否被阶段或项目引用，已引用的类型禁止删除并给出提示
- 能够对审批类型进行启用/停用，停用前校验是否有阶段正在使用，有使用时禁止停用并给出提示
- 支持审批类型编码唯一性校验，新增和修改时均须验证
- 能够以表格形式展示审批类型列表，包含名称、编码、排序、颜色标签、图标、状态开关、更新人、更新时间等字段
- 支持在列表中通过上移/下移按钮直接调整审批类型排序，排序变化即时生效并同步更新序号
- 排序调整受边界约束：首条记录不可上移，末条记录不可下移
- 支持按名称模糊搜索、按状态筛选

### 2.3.1.3 输入输出需求

**表格 3-1 审批类型配置输入输出表**

| 序号 | 信息类型 | 字段名称 | 来源/目的地 | 约束 |
|------|---------|---------|------------|------|
| In1 | 输入 | 审批类型名称 | 用户输入 | 最多5个汉字，不可重复（必填项） |
| In2 | 输入 | 审批类型编码 | 用户输入 | 英文字母、数字、下划线组成，最多20个字符（必填项） |
| In3 | 输入 | 排序序号 | 系统默认自增 | 正整数，数值越小排序越靠前 |

## 2.3.2 审批阶段配置

### 2.3.2.1 功能描述

审批阶段配置用于定义临床研究中的各个审核阶段（如预筛阶段、筛选阶段、入组阶段等），每个阶段可关联多个审批类型、配置阶段颜色与排序，为项目阶段设置提供中间层数据支撑。管理员可对审批阶段进行新增、修改、删除、启用/停用操作，并支持在列表中通过上移/下移按钮直接调整阶段排序。

### 2.3.2.2 能力要求

- 能够对审批阶段进行新增，填写阶段名称、排序、审批类型（多选）、颜色、备注等信息
- 能够对审批阶段进行修改，加载选中记录后编辑保存
- 能够对审批阶段进行删除，删除前校验是否被项目引用，已引用的阶段禁止删除并给出提示
- 能够对审批阶段进行启用/停用，停用前校验是否有项目正在使用该阶段
- 支持阶段名称唯一性校验
- 能够从已启用的审批类型配置中多选关联审批类型，至少选择1个
- 能够以表格形式展示审批阶段列表，包含阶段名称、排序、关联审批类型标签组、颜色标签、状态开关、更新人、更新时间等字段
- 支持在列表中通过上移/下移按钮直接调整阶段排序，排序变化即时生效并同步更新序号
- 排序调整受边界约束：首条记录不可上移，末条记录不可下移

## 2.3.3 项目阶段设置

### 2.3.3.1 功能描述

项目阶段设置在项目管理编辑/新建页面中，允许项目管理员为每个研究项目配置启用哪些审核阶段，并为每个阶段指定审批流程、设置知情必填规则、填写阶段备注。项目保存后，匹配详情页将按此处配置的阶段动态生成Tab，患者在不同阶段的审批流程也据此自动匹配。

### 2.3.3.2 能力要求

- 支持在项目编辑/新建页面中配置审批阶段，从已启用的审批阶段中多选
- 为每个选中的阶段配置审批流程：选择该阶段下的审批类型并指定审批人
- 支持配置「知情必填」开关（是/否），控制该阶段是否必须完成知情同意
- 支持为每个阶段独立启用/禁用以下功能模块：入排阶段、筛选表、合并药物、合并症、思考链，不同阶段可启用不同的模块组合
- 支持为每个阶段填写备注说明
- 支持启用/停用项目阶段配置，控制该项目下各阶段的整体生效状态
- 项目配置保存后，匹配详情页按阶段配置动态生成阶段Tab
- 患者进入某阶段后，提交审批时自动筛选该阶段配置的审批类型列表
- 支持查看各阶段审批完成进度

### 2.3.3.3 输入输出需求

**表格 3-3 项目阶段设置输入输出表**

| In2 | 输入 | 各阶段审批类型 | 选择（所有启用的审核类型，默认选中该阶段配置的类型） | 每个阶段从关联的审批类型中多选，至少选择1个（必填项） |
| In3 | 输入 | 知情必填 | 选择 | 是/否，控制该阶段是否必须完成知情同意 |
| In4 | 输入 | 启用入排阶段 | 选择 | 是/否，控制该阶段匹配详情页是否展示入排阶段Tab |

## 2.3.4 智能筛选-患者列表提交审核和单独的预提交按钮

### 2.3.4.1 功能描述

阶段审核列表是审核人员查看待审批患者的核心入口页面，用于按阶段和审批类型分类展示所有待审批的患者记录。审核人员可通过多维度筛选条件快速定位待审批患者，查看患者基本信息、当前阶段、审批状态，并进入匹配详情页执行审批操作。

### 2.3.4.2 能力要求

- 支持按阶段和审批类型分类展示待审批患者列表
- 支持按患者姓名（模糊搜索）、审批阶段、审批类型、审批状态（待审批/已通过/已驳回）、提交时间范围查询
- 支持支队、大队、中队级联查询，各级单位只能查看管辖范围内的审批数据
- 支持列表分页展示，包含患者姓名、项目名称、当前阶段、审批类型、审批状态、提交人、提交时间等字段
- 点击患者可跳转至匹配详情页进行审批操作（通过/驳回）
- 支持批量审批操作（勾选多条记录，统一通过或驳回）
- 支持审批状态实时更新：审批完成后列表自动刷新

### 2.3.4.3 输入输出需求

**表格 3-4 阶段审核列表输入输出表**

| 序号 | 信息类型 | 字段名称 | 来源/目的地 | 约束 |
|------|---------|---------|------------|------|

## 2.3.5 匹配详情-阶段审核

### 2.3.5.1 功能描述

匹配详情页的阶段审核功能是审核人员执行审批操作的核心工作界面。页面顶部按项目阶段配置动态生成阶段Tab（如预筛阶段/筛选阶段/入组阶段），患者信息按阶段组织展示。审核人员可在当前阶段Tab下查看匹配详情、筛选表、病史资料、思考链等信息，并执行审批通过/驳回操作。页面同时展示阶段印章、审批记录、操作按钮等关键元素。

### 2.3.5.2 能力要求

- 支持页面顶部按项目阶段配置动态生成阶段Tab，每个Tab关联该阶段的审批流程
- 各阶段下的子Tab（入排阶段、筛选表、合并药物、合并症、思考链、病史与资料）按项目阶段设置的模块开关控制显示/隐藏
- 支持提交审批功能：弹出审批表单，自动按患者当前阶段筛选可用审批类型
- 支持审批操作：通过/驳回，填写审批意见/驳回原因
- 支持右上角展示阶段印章（如"预筛阶段-待审批"）
- 支持查看审批记录：展示该患者在各阶段的审批历史时间线
- 支持右侧PRD说明面板，展示功能需求说明

### 2.3.5.3 输入输出需求

**表格 3-5 匹配详情-阶段审核输入输出表**

| In3 | 输入 | 审批意见 | 用户输入 | 最多500个汉字 |
| In4 | 输入 | 审批结果 | 选择 | 通过/驳回（必填项） |
| In5 | 输入 | 驳回原因 | 用户输入 | 审批结果为驳回时必填，最多500个汉字 |
| Out1 | 输出 | 阶段Tab | 页面 | 动态生成，每个Tab对应一个审批阶段 |
| Out2 | 输出 | 匹配详情 | 页面 | 包含匹配结果、入排标准、证据来源等 |
