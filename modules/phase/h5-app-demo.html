移动端 智能筛选患者编辑与匹配详情

患者编辑 / 项目匹配 / 匹配详情（新旧版本）/ 审核记录 / 审核列表查看

1APP 入口

  • APP 列表提供 审核列表、智能筛选 两个入口。

2智能筛选流程

  • 点击「智能筛选」进入项目列表，选择项目后进入患者列表。

3患者卡片操作

  • 患者卡片展示基本信息、标签、操作按钮。
  • 操作区含 编辑患者、提交审批 / 补充审核、审核记录、匹配详情。
  • AI 智能匹配患者显示 项目匹配 按钮；HGKD 等多版本患者需先选择入排版本。

4编辑患者

  • 点击卡片「编辑」进入编辑患者页面。
  • 筛选号、知情时间 始终可填写；是否必填与 PC 端项目配置的阶段必填项保持一致（根据阶段 informedRequired 配置）。
  • 保存时校验必填项，未填项高亮提示。

5项目匹配

  • 项目匹配逻辑与 PC 端保持一致。
  • 前端不用修改，后端需要改对应的匹配逻辑。
  • 项目匹配选择多版本的时候，只显示版本名称，不显示版本号

6提交审核/补充审核/单独点预提交

  • 1. 一直展示知情时间和筛选号，必填校验跟项目配置保持一致，
  • 2. 涉及前端的 一个文案提示修改：提交审核的检测阶段是否匹配的文案修改：「检测到您已跨阶段，需要进行入组匹配，匹配成功后系统会自动帮您提交」 改成 “检测到您已跨阶段，匹配成功后系统将自动为您提交。”。
  • 3. 匹配的逻辑跟PC保持一致

7匹配详情（新旧版本）

  • 顶部阶段标签根据项目配置动态生成（预筛、入组等），点击切换不同阶段的匹配详情。
  • 根据 PC 端页面版本配置（configureNew）展示旧版或新版匹配详情，版本切换条默认取 defaultView（按照版本配置默认页面展示），可手动切换；两个版本结构对齐 match-detail-new.html。
  • 新版（智能匹配，卡片式）：顶部 基本信息 + AI 建议（结论 + 风险提示 + 需补充资料）+ 卡片式入选/排除标准。
  • 旧版（匹配详情，卡片式）：基本信息 + 方案协议卡（方案号 / 完整标题 / 入排标准 / 更新时间）+ 匹配度统计卡（匹配度 / 待定占比 / 统计描述）+ AI 建议卡（结论 + 排除原因列表）+ 卡片式入选/排除标准（不展示源数据，保留 结果修正 / 修正记录 / 清空修正）+ 合并症 / 合并药物。

8审核记录与审核列表

  • 审核记录按项目配置的审批流程展示（预筛审核、主知情审核、入组审核等）。
  • 审核列表「查看」支持按配置打开旧版或新版匹配详情。

使用说明

  • 路径：APP 列表 → 智能筛选 → 项目 → 患者列表 → 编辑 / 项目匹配 / 提交审批 / 审核记录 / 匹配详情
  • 核心体验：编辑患者必填联动、项目匹配跨阶段、匹配详情新旧版本切换。
