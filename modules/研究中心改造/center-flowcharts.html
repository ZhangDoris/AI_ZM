2患者转移流程

参研中心 → 选择「删除 / 患者转移」→ 全部转移 或 单个转移，审核人员随目标中心变动

参研中心

转移方式？
全部患者转移
选择目标中心
· 提交人：维持不变（仍为原中心提交人）
· 审核人员：默认选中目标中心 所有 CRA + 医学 人员
提交转移申请
单个患者转移
选择目标中心
· 提交人：维持不变
· 审核人员：默认选中目标中心 所有 CRA + 医学 人员
提交该患者转移申请
目标中心审核人员接审 → 转移完成
写入「患者转移日志」

3成员管理流程

本中心成员的增删改、患者交接、离职交接，以及对应的待审核人与日志

新增成员

本中心新增成员
角色类型？
CRA / 医学
同步加入「待审核人」
CRC / 协调员
不涉及待审核人

删除 / 停用

成员名下是否已有患者？
无患者
可直接删除
有患者
不可删除 → 改用「停用 + 交接」
患者交接给另一人

交接与离职规则

CRC / 协调员 离职
  • 数据权限变更为新接手人
  • 创建人仍为原 CRC（保留溯源）
  • 名下患者交接给新人
医学 / CRA 离职
  • 原「待审核人」需改交接的人
  • 在审任务转移给接手人
  • 中心状态变更日志留痕
全局要求
  • 所有动作保留操作日志
  • 中心侧提供「患者转移日志」
  • 中心侧提供「成员变更日志」
中心侧日志：患者转移日志 + 成员变更日志（全量留痕）
